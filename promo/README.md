# ことのめ — 紹介映像

アプリの映像。1920×1080・30fps・約91秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。

見る人：ハングルが記号に見えている人。アプリの使い方より先に、**ハングルがどれだけ分かりやすいか**を速く見せ、それから、
それがアプリで学べることを見せる。はじめの一コマから問いかける（大きな ㄱ と「この字、何の形？」）。ハングルを世に出した
本『訓民正音』（1446年、鄭麟趾の序）の一文「故智者不終朝而㑹，愚者可浹旬而學」（賢い者は朝のうちにわかり、愚かな者でも
十日で学べる）は、しくみを見たあとの答え合わせに置く（はじめに見せると退屈で、数秒で離れられる）。アプリの所は姉妹
（ことのは・ことのね の映像、`../../english/promo`・`../../作成したもの/hanjaatume/promo`）と同じ作り：アプリの画面を
描き直し、その横に一文ずつ言葉を置く。ハングル学習の動画（`../film/`、爆速ハングル）とは別のもの。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | 一コマ目から、口の絵の丸の中に大きな ㄱ（後ろに顔がうすく） | この字、何の形？ |
| | ㄱ が舌の上へ降りて重なり、顔が現れる（가） | 「カキクケコ」と言うときの、舌の形。 |
| | 口の絵が左へ寄り、右に ㄴ：大きな ㄴ が舌の先へ降りる（나） | 「カキクケコ」／「ナニヌネノ」 |
| しくみ | ㄱ ㄴ ㅇ ㅁ ㅅ と口の場所 | 子音は、口の形の絵。 |
| | その下に、線を一本足した ㄷ ㅎ ㅂ ㅈ（足した線はアクセント）。나 → 다 | 同じ場所で、線を一本足すと、別の音。 |
| | ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ が、音（아 어 오 우 으 이）といっしょに | 母音は、六つ。 |
| | ㄴ ㅏ ㅁ ㅜ が四角に組み上がって 나무、木 | 組み合わせると、ひとつの音。 |
| | 라디오・바나나・드라마 が書かれて鳴る | 16字で、もう読める。 |
| 答え合わせ | 『訓民正音』の一文が、罫線の間に縦二行で（すばやく）。訳が二行。「不終朝」が灯る | 賢い者は、朝のうちにわかり、愚かな者でも、十日で学べる。/ 朝のうちに、読みはじめられる。 |
| 名前 | アイコンと ことのめ | 16字だけ知って、あとは浴びる。 |
| 最初の16字 | アプリの ㅁ の口のページ（くちびるを閉じ、字が書かれ、離れて 마） | 最初の16字は、アプリでひとつずつ。 |
| 浴びる | 6つの語が降る。카드 を押すと音と意味と字（ㅋ は点線）。ㅋ を押すと字のシート（카、ㄱ → ㅋ、キーの場所） | 音つきの語が、雨のように降ってくる。/ 知らない字は、押せばその場で。 |
| 打ってみる | 카드 を두벌식で。ㅋ を ㄱ と打ち間違えて ⌫、打ち直す。打ち終えると 카드 | 聞いた語を、自分の指で打つ。 |
| 終わり | 名前、タブ（浴びる・打つ・自分） | 登録はいりません。 |

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。16字 → 十六文字（「じゅうろくじ」は 16時 と聞こえる）。字母は読ませない）。
  Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのは と同じサービスアカウント
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
  `--check` で書き起こして台本と並べる（「ナがタに」は「長が谷に」と聞こえたので「ナ行がタ行に」に、「本当でしょうか。」は
  「か」が落ちたので「？」で作り直した）。
- 韓国語の語と音節：アプリ自身の声（`../public/audio/kore`、音声認識で確かめたもの）を `public/app/clips` に写して使う。
  ここでは作らない。
- 映像の時は、声の長さから決まる（`src/voice.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。声を作り直したら `music` も走らせ直す。
- 音楽と小さな音は `scripts/music.py`（ことのは・ことのね と同じ作り方）。だれかの曲は使っていない。
- 耳で聞いての確かめ（声の感じ・速さ・音量のつり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコン、アプリの声、字（Google Fonts の倉庫から取り、映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../../english/.env.local   # ナレーション（まだ無いものだけ。--force・--only V01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonome-promo.mp4
npm run card       # 一目でわかる紹介画像 out/kotonome-card.png（src/Card.tsx）
npm run stills -- 300 1240     # 1コマだけ out/stills に
```

- 字（ハングル）はアプリと同じ自前の線で描く：`../src/lib/glyph.ts` の形をそのまま読み込み、書き順の描き込みはコマで
  決める（`src/glyph.tsx`）。口の絵はアプリの `Mouth.tsx` と同じ絵を、コマで動くように移したもの（`src/mouth.tsx`）。
  두벌식の配列と打ったときの組み上がりも、アプリの `../src/lib/dubeol.ts` をそのまま使う。
- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。アプリの見た目や言葉を変えたら、ここも変える。
- 字（IBM Plex Sans JP・IBM Plex Sans KR・しっぽり明朝、引用は Noto Serif SC の太さ700）は映像に出てくる字だけに
  切ってある。引用の 㑹（會 の異体）は、しっぽり明朝にも Plex にも無く、Noto Serif SC にある。言葉を変えたら `assets`
  を走らせ直す。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ。JPEG のコマのままだと薄い灰色が白く飛ぶ）。
- 見せる中身は `../CONCEPT.md` のとおり：点数・正答率・連続記録は出さない。
