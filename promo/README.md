# ことのめ — 紹介映像

アプリの映像。1920×1080・30fps・約99秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリ ことのは・ことのね の映像（`../../english/promo`・`../../作成したもの/hanjaatume/promo`）にそろえた：
アプリの画面を描き直し、その横に一文ずつ言葉を置く。

見る人：ハングルが記号に見えていて、字の表を前に止まっている人。最初の90秒だけで読みはじめられること、そのあとは
音つきの語を浴び、知らない字はその場で、聞いた語はふつうの韓国語キーボードで自分の指で打つ、を見せる。
ハングル学習の動画（`../film/`、爆速ハングル）とは別のもの。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | 記号に見える語（라디오・바나나・드라마・커피・김치） | ハングル、記号に見えていませんか？ |
| | 口の絵：「カキクケコ」の舌が上がり、その形が ㄱ として書かれ、絵から離れる（가） | 「カキクケコ」と言うとき、舌の奥が上がる。その形が、ㄱ。 |
| | ㄱ ㄴ ㅇ ㅁ ㅅ と口の場所 | 子音は、口の形の絵。 |
| | 字母が四角に組み上がって 라디오（라디오）、ラジオ | 90秒で、もう読める。 |
| 名前 | アイコンと ことのめ | 90秒だけ知って、あとは浴びる。 |
| 最初の90秒 | 思い出す：나 → ㄴ。아 で ㄱ を押して間違え、口の絵（「アー」）、ㅇ。가 → ㄱ | 少し見たら、すぐ何度も思い出す。 |

| 打ってみる | 카드 を두벌식で。ㅋ を ㄱ と打ち間違えて ⌫、打ち直す。打ち終えると 카드 | 聞いた語を、自分の指で打つ。 |

| また出会う | 雨のおわり（はじめての字 ㅋ、打ち間違えた字 ㅋ、次の90秒の案内）。次の雨で 코스・크다・키 が紫で降る | 打ち間違えた字は、また降ってくる。 |

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。90秒 → 九十秒。字母は読ませない）。
  Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。鍵は ことのは と同じサービスアカウント
  （`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`）。鍵はこのリポジトリに置かない。
  `--check` で書き起こして台本と並べる（V13 は「となりに」の「に」が落ちたので作り直した）。
- 韓国語の語と音節：アプリ自身の声（`../public/audio/kore`、音声認識で確かめたもの）を `public/app/clips` に写して使う。
  例文の声は ことのあめ のもの（公開の置き場から `public/app/line.wav` に）。ここでは作らない。
- 映像の時は、声の長さから決まる（`src/voice.json`・`src/clips.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。声を作り直したら `music` も走らせ直す。
- 音楽と小さな音は `scripts/music.py`（ことのは・ことのね と同じ作り方）。だれかの曲は使っていない。
- 耳で聞いての確かめ（声の感じ・速さ・音量のつり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコン、アプリの声、例文の声、字（Google Fonts の倉庫から取り、映像に出てくる字だけに切る。Python の fontTools）
npm run voice -- --env ../../english/.env.local   # ナレーション（まだ無いものだけ。--force・--only V01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonome-promo.mp4
npm run card       # 一目でわかる紹介画像 out/kotonome-card.png（src/Card.tsx）
npm run stills -- 300 1240     # 1コマだけ out/stills に
```

- 字（ハングル）はアプリと同じ自前の線で描く：`../src/lib/glyph.ts` の形をそのまま読み込み、書き順の描き込みはコマで
  決める（`src/glyph.tsx`）。口の絵はアプリの `Mouth.tsx` と同じ絵を、コマで動くように移したもの（`src/mouth.tsx`）。
  두벌식の配列と打ったときの組み上がりも、アプリの `../src/lib/dubeol.ts` をそのまま使う。
- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。アプリの見た目や言葉を変えたら、ここも変える。
- 字（IBM Plex Sans JP・IBM Plex Sans KR・しっぽり明朝）は映像に出てくる字だけに切ってある。言葉を変えたら `assets` を
  走らせ直す。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ。JPEG のコマのままだと薄い灰色が白く飛ぶ）。
- 見せる中身は `../CONCEPT.md` のとおり：点数・正答率・連続記録は出さない。
